Methodology & limitations

Data sources

  • Dr. Duke's Phytochemical and Ethnobotanical Databases (USDA Agricultural Research Service, public domain), distributed as open data on Ag Data Commons and Zenodo. Tables used: FNFTAX (taxonomy), FARMACY_NEW (plant–chemical links), COMMON_NAMES, ETHNOBOT (traditional uses with country and reference), AGGREGAC (chemical–activity records with dosage and reference), ACTIVITIES (bioactivity vocabulary), REFERENCES (full citations).

How matching works

Each traditional use is compared with the recorded bioactivities of the plant's constituents. A direct match shares a normalised term with the use (for example ANTIDIABETIC against the use diabetes); a related match shares a word stem (for example ANALGESIC against analgesia). Matches are generated mechanically and are labelled as leads.

What this tool does not do

  • It does not assert that any plant or constituent treats, cures, or prevents any condition.
  • It does not measure dose, safety, or efficacy; recorded dosages in the source database are shown where present, but the app makes no recommendations.
  • Absence of a match means absence in this dataset, not scientific disproof.
  • It is not a substitute for professional medical advice.

Reproducibility

The full build pipeline is in pipeline/ in the repository: it downloads the source tables and reconstructs the SQLite database this app serves, so every number on every page can be regenerated and audited.
